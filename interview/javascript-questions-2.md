## 1. `this`는 어떻게 결정되나요?

**답변:**
호출 방식에 따라 런타임에 결정된다. ① 일반 호출 → 전역(strict면 `undefined`), ② 메서드 호출 → 그 객체, ③ `new` → 새 인스턴스, ④ `call/apply/bind` → 명시한 값. 화살표 함수만 예외(정의 위치의 this).

## 2. 화살표 함수의 `this`는?

**답변:**
자신의 `this`가 없어 **정의된 위치의 상위 스코프 this를 렉시컬하게** 가져온다(바인딩 불가). 그래서 콜백·이벤트 핸들러에서 this 유지에 유용하지만, 객체 메서드나 `new`에는 부적합하다.

## 3. `call`/`apply`/`bind` 차이는?

**답변:**
셋 다 this를 지정한다. `call(this, a, b)`은 즉시 호출(인자 나열), `apply(this, [a,b])`도 즉시 호출(인자 배열), `bind`는 호출하지 않고 this가 고정된 **새 함수를 반환**한다.

## 4. 일급 함수·고차 함수란?

**답변:**
일급 함수는 함수를 변수에 담고·인자로 넘기고·반환할 수 있음(JS는 일급). 고차 함수는 함수를 인자로 받거나 반환하는 함수(`map`, `filter`, 디바운스). 함수형 패턴의 토대.

## 5. 클로저란 무엇이고 어디에 쓰나요?

**답변:**
함수가 **자신이 선언된 렉시컬 환경(변수)을 기억**해, 바깥 함수가 끝나도 그 변수에 접근하는 것. 용도: 데이터 은닉(모듈 패턴·private 변수), 상태 유지(카운터), 부분 적용/커링, 콜백의 컨텍스트 보존.

## 6. 반복문 + `var` 클로저 함정은?

**답변:**
`var`는 함수 스코프라 반복문이 끝난 뒤 콜백이 모두 **같은 마지막 i**를 참조한다.

```javascript
for (var i = 0; i < 3; i++) setTimeout(() => console.log(i)); // 3,3,3
for (let i = 0; i < 3; i++) setTimeout(() => console.log(i)); // 0,1,2
```

`let`은 블록 스코프라 반복마다 새 바인딩이 생겨 의도대로 동작한다.

## 7. TDZ(일시적 사각지대)란?

**답변:**
`let`/`const`는 선언 전 참조하면 `ReferenceError`가 나는 구간(스코프 시작~선언)이 있다. 호이스팅은 되지만 초기화 전이라 접근 불가. `var`(undefined로 초기화)와 달리 실수를 빨리 잡아준다.

## 8. 호이스팅은 어떻게 동작하나요?

**답변:**
선언이 스코프 최상단으로 끌어올려지는 것처럼 동작한다. `var`는 `undefined`로 초기화돼 선언 전 접근 시 undefined, 함수 선언은 통째로 끌어올려져 선언 전 호출 가능. `let/const`는 TDZ에 걸린다.

## 9. 프로토타입 체인이란?

**답변:**
객체는 `[[Prototype]]`로 부모 객체를 가리키고, 속성 조회 시 자신에 없으면 체인을 따라 위로 탐색한다(없으면 `null`까지). 상속과 메서드 공유의 메커니즘이며, 끝에 `Object.prototype`이 있다.

## 10. `class`는 프로토타입과 어떤 관계인가요?

**답변:**
`class`는 프로토타입 기반 상속의 **문법 설탕**이다. 메서드는 `prototype`에 올라가고 `extends`는 프로토타입 체인을 연결한다. 내부 동작은 기존 프로토타입과 동일하되 문법이 명확하고 `super`·private 필드 등을 제공한다.

## 11. 얕은 복사와 깊은 복사는?

**답변:**
얕은 복사(`{...obj}`, `Object.assign`)는 1단계만 복사해 중첩 객체는 참조를 공유한다. 깊은 복사는 모든 단계를 복제(`structuredClone(obj)`, 과거엔 JSON 우회). 중첩 객체를 독립적으로 다루려면 깊은 복사가 필요하다.

## 12. `==`와 `===`의 차이는?

**답변:**
`==`는 타입이 다르면 강제 변환 후 비교(`'1' == 1` → true), `===`는 타입과 값이 모두 같아야 true. 예측 불가한 변환을 피하려 `===`를 기본으로 쓴다. 예외적으로 `== null`은 null/undefined를 한 번에 거르는 관용구.

## 13. 마이크로태스크와 매크로태스크 순서는?

**답변:**
한 콜스택이 비면 **마이크로태스크 큐(Promise.then, queueMicrotask)를 전부** 비우고, 그다음 매크로태스크(setTimeout, I/O) **하나**를 처리한 뒤 다시 마이크로태스크를 비운다. 그래서 Promise가 setTimeout보다 항상 먼저 실행된다.

## 14. `Promise.all`/`race`/`allSettled`/`any` 차이는?

**답변:**
`all`: 모두 성공 시 결과 배열, 하나라도 실패면 즉시 reject. `allSettled`: 모두 끝날 때까지 기다려 성공/실패 상태 배열. `race`: 가장 먼저 끝난(성공이든 실패든) 것. `any`: 가장 먼저 **성공**한 것, 모두 실패면 AggregateError.

## 15. async 함수의 반환값은?

**답변:**
항상 Promise다. 값을 return하면 resolve된 Promise로 감싸지고, throw하면 reject된 Promise가 된다. 그래서 호출부에서 `await`나 `.then`으로 받는다.

## 16. 병렬 vs 순차 await는?

**답변:**
독립적인 비동기 작업을 순차 await하면 불필요하게 느리다.

```javascript
// ❌ 순차: 합이 걸림
const a = await fetchA(); const b = await fetchB();
// ✅ 병렬: 동시에 시작 후 함께 대기
const [a, b] = await Promise.all([fetchA(), fetchB()]);
```

서로 의존하면 순차, 독립이면 `Promise.all`로 병렬.

## 17. 원시 타입과 참조 타입의 차이는?

**답변:**
원시(number, string, boolean, null, undefined, symbol, bigint)는 **값으로** 복사·전달되고 불변. 객체/배열/함수는 **참조로** 전달돼 한쪽 변경이 공유된다. 함수 인자 전달·복사 동작의 차이를 만든다.

## 18. `null`과 `undefined`의 차이는?

**답변:**
`undefined`는 "값이 할당되지 않음"(선언만 한 변수, 없는 속성, 반환 없는 함수). `null`은 "의도적으로 빈 값". `typeof undefined === 'undefined'`, `typeof null === 'object'`(역사적 버그).

## 19. falsy 값 8가지는?

**답변:**
`false`, `0`, `-0`, `0n`(BigInt 0), `""`, `null`, `undefined`, `NaN`. 이 외는 모두 truthy(빈 배열 `[]`·빈 객체 `{}`도 truthy임에 주의).

## 20. `NaN`의 특이점은?

**답변:**
`NaN`은 자기 자신과도 같지 않다(`NaN === NaN` → false). 그래서 검사는 `Number.isNaN(x)`나 `Object.is(x, NaN)`로 한다. 숫자 변환 실패(`Number('a')`)의 결과다.

## 21. JS 메모리 누수의 원인은?

**답변:**
의도치 않은 전역 변수, 제거 안 한 이벤트 리스너·타이머(`setInterval`), 클로저가 큰 객체를 계속 참조, 분리된(detached) DOM 노드를 JS가 붙들고 있음, 무한 증가 캐시. DevTools 힙 스냅샷으로 추적한다.

## 22. `WeakMap`/`WeakSet`은 왜 쓰나요?

**답변:**
키를 **약하게 참조**해, 키 객체가 다른 곳에서 참조되지 않으면 GC가 회수한다(메모리 누수 방지). DOM 노드에 메타데이터 연결, 캐시처럼 객체 생명주기에 묶인 데이터에 적합. 열거 불가·크기 없음.

## 23. 디바운스를 구현해보세요

```javascript
function debounce(fn, delay) {
  let timer;
  return function (...args) {
    clearTimeout(timer);                         // 이전 예약 취소
    timer = setTimeout(() => fn.apply(this, args), delay); // 마지막 호출만 실행
  };
}
```

**답변 포인트:** 클로저로 `timer`를 유지하고, 매 호출마다 이전 타이머를 취소해 "마지막 호출 후 delay 동안 잠잠하면 1회 실행". 검색 입력·리사이즈에 쓴다. (throttle은 일정 간격마다 1회.)

## 24. 이벤트 위임(delegation)이란?

**답변:**
자식마다 리스너를 붙이는 대신 **공통 부모 하나에 리스너**를 달고, 이벤트 버블링으로 올라온 `event.target`으로 어떤 자식인지 판별한다. 동적으로 추가되는 요소도 자동 처리되고 리스너 수가 줄어 메모리·성능에 유리하다.
