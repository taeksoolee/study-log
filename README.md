# 프론트엔드 개발자 성장 로그

> 기초부터 심화까지, 프론트엔드 개발자로 성장하는 모든 과정을 기록합니다.

## 학습 방식
- Claude가 문서 작성 → 읽고 질문하는 방식
- 각 문서는 개념 설명 + 예제 코드 + 면접 포인트 포함
- 진행 상태: ✅ 완료 / 🔄 진행 중 / ⬜ 예정
