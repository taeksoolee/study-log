## 학습 목표

- 대규모 프론트엔드 프로젝트에서 사용되는 아키텍처 패턴을 이해한다
- 각 패턴의 장단점과 적합한 사용 시나리오를 구분할 수 있다
- 실제 코드 예시를 통해 패턴을 적용하는 방법을 익힌다
- 면접에서 아키텍처 관련 질문에 자신 있게 답변할 수 있다

## 학습 순서 추천

1. **입문**: Atomic Design → MVC/MVP/MVVM
2. **중급**: Feature-Sliced Design → Clean Architecture
3. **고급**: 마이크로 프론트엔드 → 모노레포 아키텍처
