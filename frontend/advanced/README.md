## 학습 목표

- 시니어 레벨 면접에서 요구하는 깊이 있는 답변을 준비한다
- 이론을 넘어 "실제로 어떻게 구현하는가"에 집중한다
- 각 문서는 기존 커리큘럼(JS 심화, React, 브라우저 등)과 Case Studies를 연결한다

## 학습 순서 추천

1. **즉시 효과**: 상태관리 판단 기준 (03) → 인증/인가 패턴 (06)
2. **면접 핵심**: RSC 심화 (01) → 웹 성능 (02) → 에러 처리 (05)
3. **차별화**: CI/CD (04) → 보안 (08) → 디자인 시스템 (09)
4. **트렌드**: AI 워크플로 (07)
