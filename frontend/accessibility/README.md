# 웹 접근성 (Accessibility, a11y)

> 모든 사용자가 — 장애 여부와 무관하게 — 웹을 인지·조작·이해할 수 있도록 만드는 기술과 원칙.

접근성은 "선택적 배려"가 아니라 **품질의 일부**다. 시맨틱 HTML과 키보드 지원을 제대로 하면 대부분의 a11y 요구사항이 자연히 충족되며, SEO·유지보수성·테스트 용이성까지 함께 좋아진다.
