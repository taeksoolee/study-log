# 검색 엔진 최적화 (SEO)

> 프론트엔드 관점의 **기술적 SEO(Technical SEO)** — 콘텐츠 마케팅이 아니라, 검색 엔진이 사이트를 잘 **크롤링·렌더링·인덱싱·이해**하도록 만드는 엔지니어링.

SPA 시대에 SEO는 프론트엔드의 책임이 됐다. JS로 렌더된 콘텐츠를 크롤러가 못 보면 검색에 안 잡힌다. 렌더링 전략(SSR/SSG)·메타데이터·구조화 데이터·성능이 모두 검색 노출과 직결된다.
