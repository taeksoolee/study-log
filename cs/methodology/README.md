```

       ↓

       ↓
03 SOLID (객체지향 설계 원칙)
       ↓
02 DDD (도메인 중심 아키텍처 설계)
```

---

## 핵심 포인트 요약

- **TDD**: 테스트 → 코드 → 리팩터링 사이클로 설계를 개선하는 방법론
- **DDD**: 비즈니스 도메인 모델 중심으로 소프트웨어를 설계하는 접근법
- **SOLID**: 유지보수하기 좋은 객체지향 코드를 위한 5가지 설계 원칙
- **클린 코드**: 읽기 쉽고 변경이 쉬운 코드를 작성하는 구체적 기법
- **애자일**: 빠른 피드백 루프와 팀 협업을 통해 가치를 점진적으로 전달하는 방식
