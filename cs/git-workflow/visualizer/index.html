커밋 타입 & 의미

feat 새로운 기능 추가
fix 버그 수정
docs 문서 변경
style 코드 스타일 (포맷 등)
refactor 리팩토링
test 테스트 추가·수정
chore 빌드·설정 변경
perf 성능 개선
revert 이전 커밋 되돌리기
ci CI 파이프라인 변경
예시 커밋 메시지
feat(auth): 소셜 로그인 기능 추가

Google OAuth 2.0 연동으로 소셜 로그인 기능을 구현했습니다.
기존 이메일 로그인 흐름에 영향을 주지 않도록 분리했습니다.

BREAKING CHANGE: /api/v1/login 엔드포인트 응답 구조 변경
Closes #42

구조: <type>(scope): <subject>
Breaking Change 는 footer에 BREAKING CHANGE: 를 작성하면 자동으로 major 버전이 올라갑니다 (semantic-release 사용 시).
