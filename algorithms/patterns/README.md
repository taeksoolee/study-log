## 패턴 선택 가이드

| 상황 | 추천 패턴 |
|------|----------|
| 정렬된 배열에서 쌍 찾기 | 투 포인터 |
| 연속된 부분 배열 문제 | 슬라이딩 윈도우 |
| 최단 경로, 레벨 순회 | BFS |
| 가능한 모든 경우 탐색 | DFS/백트래킹 |
| 최적 부분 구조 | 동적 프로그래밍 |
| 지역 최적 → 전역 최적 | 그리디 |
| 정렬, 분할 문제 | 분할 정복 |
