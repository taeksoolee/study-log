## 1. 신장 트리와 MST

**신장 트리(spanning tree)**: 그래프의 모든 정점을 사이클 없이 연결하는 부분 그래프(간선 V-1개). **MST(최소 신장 트리)**: 간선 가중치 합이 최소인 신장 트리. "모든 도시를 최소 비용으로 잇는 도로망"이 전형적 문제.

두 그리디 알고리즘이 표준: **크루스칼**(간선을 싼 것부터), **프림**(정점을 가까운 것부터).

---

## 2. 크루스칼 (Kruskal) — 간선 중심

간선을 **가중치 오름차순 정렬** 후, 사이클을 만들지 않는 간선만 채택. 사이클 판정은 **유니온 파인드**([패턴 12](./12-union-find.md)).

```javascript
function kruskal(n, edges) {            // edges: [u, v, w]
  edges.sort((a, b) => a[2] - b[2]);   // 가중치 오름차순
  const dsu = new DSU(n);
  let total = 0, count = 0;
  for (const [u, v, w] of edges) {
    if (dsu.union(u, v)) {             // 사이클 안 생기면 채택
      total += w;
      if (++count === n - 1) break;    // 간선 V-1개면 완성
    }
  }
  return count === n - 1 ? total : -1;  // -1: 연결 불가(그래프 비연결)
}
// 시간 O(E log E) (정렬 지배)
```

> 희소 그래프(간선 적음)에 유리. 간선 리스트만 있으면 바로 적용.

## 3. 프림 (Prim) — 정점 중심

한 정점에서 시작해 **현재 트리에 가장 가깝게 붙는 간선**을 최소 힙으로 골라 확장(다익스트라와 골격이 비슷).

```javascript
function prim(adj, n) {                 // adj[u] = [[v, w], ...]
  const inMST = new Array(n).fill(false);
  const pq = new MinHeap();             // [가중치, 정점]
  pq.push([0, 0]);
  let total = 0, count = 0;
  while (pq.size() && count < n) {
    const [w, u] = pq.pop();
    if (inMST[u]) continue;             // 이미 포함 → 스킵
    inMST[u] = true; total += w; count++;
    for (const [v, wt] of adj[u]) if (!inMST[v]) pq.push([wt, v]);
  }
  return count === n ? total : -1;
}
// 시간 O(E log V) (이진 힙)
```

> 밀집 그래프(간선 많음)에 유리. 인접 리스트 + 힙으로 다익스트라처럼 동작.

## 4. 크루스칼 vs 프림

| | 크루스칼 | 프림 |
|--|---------|------|
| 접근 | 간선을 싼 것부터(전역) | 정점을 가까운 것부터(트리 성장) |
| 자료구조 | 정렬 + 유니온 파인드 | 최소 힙 + 인접 리스트 |
| 복잡도 | O(E log E) | O(E log V) |
| 유리한 그래프 | 희소(E 작음) | 밀집(E 큼) |
| 입력 형태 | 간선 리스트 | 인접 리스트 |

> 둘 다 그리디지만 정당성이 보장된다(아래 컷 성질). 일반적으로 간선 리스트가 주어지면 크루스칼이 구현이 간단해 자주 선택된다.

---

## 5. 핵심 성질 (컷 성질·사이클 성질)

- **컷 성질(cut property)**: 그래프를 두 집합으로 나누는 임의의 컷에서, 그 컷을 가로지르는 **가장 가벼운 간선은 어떤 MST에 반드시 포함**된다 → 프림·크루스칼의 채택이 안전한 이유.
- **사이클 성질(cycle property)**: 임의 사이클에서 **가장 무거운 간선은 어떤 MST에도 포함되지 않는다** → 크루스칼이 사이클 만드는 간선을 버리는 근거.

> 이 두 성질이 "지역적 그리디 선택이 전역 최적"임을 보장한다.

---

## 6. 응용

- 네트워크/도로/전력망 최소 비용 연결.
- **최소 병목 신장 트리**(경로상 최대 간선 최소화)도 MST가 답을 준다.
- 클러스터링(가장 비싼 k-1개 간선을 끊으면 k개 군집).
- 근사 알고리즘(외판원 2-근사에 MST 활용).

---

## 7. 면접 포인트

**Q. MST란 무엇인가요?**
> 그래프의 모든 정점을 사이클 없이 연결(간선 V-1개)하면서 가중치 합이 최소인 부분 그래프다. 모든 노드를 최소 비용으로 잇는 문제에 쓰며 크루스칼·프림으로 구한다.

**Q. 크루스칼과 프림의 차이와 선택 기준은?**
> 크루스칼은 간선을 가중치순으로 정렬해 사이클을 안 만드는 것만 유니온 파인드로 채택(O(E log E)), 프림은 한 정점에서 힙으로 가장 가까운 정점을 붙여 트리를 키운다(O(E log V)). 희소 그래프·간선 리스트면 크루스칼, 밀집 그래프·인접 리스트면 프림이 유리하다.

**Q. 크루스칼에서 사이클을 어떻게 판정하나요?**
> 유니온 파인드로 간선의 두 끝점이 이미 같은 집합인지 본다. 같으면 사이클을 만들므로 버리고, 다르면 union으로 합치며 채택한다.

**Q. 그리디인데 왜 최적이 보장되나요?**
> 컷 성질 때문이다. 정점을 둘로 나누는 임의의 컷을 가로지르는 가장 가벼운 간선은 항상 어떤 MST에 포함된다. 프림·크루스칼의 매 선택이 이 성질을 만족해 전역 최적이 보장된다.

**Q. 프림과 다익스트라의 차이는?**
> 골격(힙으로 최소 키 정점 확장)은 비슷하지만, 프림은 "트리에서 정점까지의 간선 하나 비용"을, 다익스트라는 "시작점부터의 누적 거리"를 키로 쓴다. 목적도 MST(전체 연결 최소) vs 최단 경로로 다르다.
