## 1. Z 알고리즘 — 접두사 매칭

`Z[i]` = 문자열 S에서 **S[i..]가 S의 접두사와 일치하는 최대 길이**. KMP의 대안으로, 패턴 매칭·주기성 문제에 쓴다. O(n).

```javascript
function zArray(s) {
  const n = s.length, z = new Array(n).fill(0);
  let l = 0, r = 0;                       // 현재 [l,r] = 가장 오른쪽 Z-박스
  for (let i = 1; i < n; i++) {
    if (i < r) z[i] = Math.min(r - i, z[i - l]); // 박스 안이면 재활용
    while (i + z[i] < n && s[z[i]] === s[i + z[i]]) z[i]++; // 확장
    if (i + z[i] > r) { l = i; r = i + z[i]; }   // 박스 갱신
  }
  return z;
}
// 패턴 매칭: Z(P + '\0' + T) 에서 z값이 |P|인 위치 = 매칭
```

> 핵심: 이미 계산한 "Z-박스" 정보를 재활용해 재비교를 줄인다. 텍스트 인덱스가 뒤로 안 가서 O(n+m).

## 2. 트라이 응용 — 다중 패턴·XOR 최대

트라이([구현](../../interview/coding-test-guide.md))는 단순 사전 외에도:
- **다중 패턴 사전 매칭**: 여러 단어를 한 트라이에 넣고 텍스트를 훑으며 동시 검색(아호-코라식의 토대).
- **자동완성**: prefix 노드의 서브트리 단어들.
- **이진 트라이로 XOR 최대화**: 수를 비트(상위→하위)로 트라이에 넣고, 각 수에 대해 **반대 비트**를 따라가 최대 XOR 짝을 O(32)에 찾음.

## 3. 아호-코라식 (Aho-Corasick)

**여러 패턴을 텍스트에서 동시에** 찾는다(스팸 필터·금칙어·바이러스 시그니처). 트라이 + KMP의 실패 링크를 결합한 것.

- 모든 패턴을 **트라이**로 구성.
- 각 노드에 **실패 링크(failure link)**: 매칭 실패 시 갈 곳 = 현재까지 매칭된 접미사가 다른 패턴의 접두사인 가장 긴 노드(KMP의 실패 함수를 트라이로 일반화). BFS로 구축.
- 텍스트를 한 번 훑으며 실패 링크를 따라 모든 패턴 등장을 찾음.
- 복잡도: 전처리 O(Σ패턴 길이), 매칭 O(텍스트 길이 + 매칭 수).

> "패턴이 여러 개"면 각 패턴마다 KMP를 돌리는 대신 아호-코라식 한 번. 다중 패턴 매칭의 표준.

## 4. 접미사 배열 (Suffix Array) 개념

문자열의 **모든 접미사를 사전순 정렬한 인덱스 배열**. 부분 문자열 검색·서로 다른 부분 문자열 수·최장 반복 부분 문자열에 쓴다.

- 구축: 단순 O(n² log n), 효율적으론 O(n log n)(접두사 두 배씩 정렬) 또는 O(n)(DC3).
- **LCP 배열**(인접 접미사의 최장 공통 접두사)과 함께 쓰면 강력.
- 접미사 트리의 메모리 효율적 대안.

> 코테에선 개념·용도 이해 위주(구현은 라이브러리/템플릿). "부분 문자열 다수 질의"의 신호.

## 5. 회문 — Manacher 개념

모든 위치를 중심으로 한 **최장 회문 반지름**을 O(n)에 구한다(중심 확장 O(n²)의 개선). 문자 사이에 구분자를 넣어 홀짝을 통일하고, 이미 구한 회문의 대칭성을 재활용한다(Z 알고리즘과 유사한 박스 재활용 아이디어).

```javascript
// 단순 중심 확장 O(n²) — 코테 다수 케이스엔 충분
function longestPalindrome(s) {
  let best = '';
  const expand = (l, r) => {
    while (l >= 0 && r < s.length && s[l] === s[r]) { l--; r++; }
    return s.slice(l + 1, r);
  };
  for (let i = 0; i < s.length; i++) {
    for (const p of [expand(i, i), expand(i, i + 1)])  // 홀/짝 중심
      if (p.length > best.length) best = p;
  }
  return best;
}
```

## 6. 선택 가이드

| 문제 | 알고리즘 |

| 단일 패턴 매칭 | KMP / Z |
| 다중 패턴 동시 매칭 | 아호-코라식 |
| prefix 검색·자동완성 | 트라이 |
| 최대 XOR 짝 | 이진 트라이 |

| 최장 회문 | 중심 확장(O(n²)) / Manacher(O(n)) |

## 7. 면접 포인트

**Q. Z 알고리즘은 무엇을 계산하나요?**
> `Z[i]`는 S[i..]가 S의 접두사와 일치하는 최대 길이다. 이미 구한 "Z-박스"를 재활용해 O(n)에 구하며, `Z(패턴+구분자+텍스트)`에서 z가 패턴 길이인 위치가 매칭이라 KMP의 대안이 된다.

**Q. 아호-코라식은 언제 쓰나요?**
> 여러 패턴을 텍스트에서 동시에 찾을 때(금칙어·스팸·시그니처). 패턴들을 트라이로 만들고 KMP의 실패 함수를 일반화한 실패 링크를 BFS로 붙여, 텍스트를 한 번만 훑어 모든 패턴 등장을 O(텍스트+매칭수)에 찾는다.

**Q. 트라이로 최대 XOR 짝을 어떻게 구하나요?**
> 수를 상위 비트부터 이진 트라이에 넣고, 각 수에 대해 각 비트에서 가능하면 반대 비트 자식으로 내려가면 XOR이 최대가 된다. 한 수당 O(비트수)=O(32).

**Q. 접미사 배열은 무엇이고 어디에 쓰나요?**
> 모든 접미사를 사전순 정렬한 인덱스 배열이다. LCP 배열과 함께 부분 문자열 검색, 서로 다른 부분 문자열 수, 최장 반복 부분 문자열을 효율적으로 푼다. 접미사 트리의 메모리 효율적 대안이다.

**Q. 최장 회문을 O(n)에 구하는 방법은?**
> Manacher 알고리즘. 구분자로 홀짝을 통일하고, 이미 구한 회문의 대칭성을 재활용해 각 중심의 회문 반지름을 O(n)에 구한다. 코테 다수 케이스는 O(n²) 중심 확장으로도 충분하다.
