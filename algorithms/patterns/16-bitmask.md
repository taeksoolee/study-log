## 1. 개념: 집합을 정수로

원소 N개의 부분집합을 **N비트 정수**로 표현한다. i번째 비트가 1이면 i번째 원소를 포함.

```
집합 {0, 2, 3}  →  비트  1101 (2진)  =  13 (10진)
                       3210 (인덱스)
```

- 부분집합 전체 = `0 ~ (2^N - 1)` 정수 순회.
- 집합 연산이 비트 연산 한 번에: 합집합 `|`, 교집합 `&`, 차집합 `& ~`, 대칭차 `^`.
- N ≤ 20 정도일 때 "모든 부분집합 탐색"의 상태를 정수로 압축 → DP 메모이제이션 키로 활용.

## 2. 기본 비트 연산 모음

```javascript
const bit = 1 << i;           // i번째 비트만 1

mask | (1 << i)               // i번째 원소 추가
mask & ~(1 << i)              // i번째 원소 제거
mask ^ (1 << i)              // i번째 원소 토글
(mask >> i) & 1               // i번째 원소 포함 여부 (1/0)

mask & (mask - 1)             // 최하위 1비트 제거
mask & (-mask)                // 최하위 1비트만 추출 (LSB)
mask === 0                    // 공집합
mask === (1 << n) - 1         // 전체 집합(꽉 참)
```

비트 개수 세기(popcount):

```javascript
function popcount(x) {
  let c = 0;
  while (x) { x &= x - 1; c++; } // 1비트를 하나씩 끔
  return c;
}
// 또는 32비트 한정: (x >>> 0).toString(2)의 '1' 개수
```

## 3. 부분집합 순회

특정 마스크의 **부분집합만** 순회하는 관용구 (집합 DP에서 자주 등장).

```javascript
// mask의 모든 부분집합(자신 포함, 공집합 포함)을 내림차순으로
for (let sub = mask; ; sub = (sub - 1) & mask) {
  // sub 사용
  if (sub === 0) break;
}
```

> `(sub - 1) & mask`가 핵심: mask에 속한 비트만 유지하며 다음 작은 부분집합으로 내려간다. 전체 복잡도는 모든 마스크에 대해 O(3^N)(각 원소가 "밖/부분집합 안 포함/부분집합 안 included" 3상태).

## 4. 비트마스크 DP — 외판원 문제(TSP)

"모든 도시를 한 번씩 방문하는 최소 비용 경로". 상태 = `(방문한 도시 집합 mask, 현재 도시 u)`. 방문 집합을 비트마스크로 압축해 DP.

```javascript
function tsp(dist, n) {
  const FULL = (1 << n) - 1;
  // dp[mask][u] = mask를 방문했고 현재 u에 있을 때 최소 비용
  const dp = Array.from({length: 1 << n}, () => new Array(n).fill(Infinity));
  dp[1][0] = 0;                       // 0번 도시에서 시작

  for (let mask = 1; mask <= FULL; mask++) {
    for (let u = 0; u < n; u++) {
      if (dp[mask][u] === Infinity) continue;
      if (!((mask >> u) & 1)) continue;
      for (let v = 0; v < n; v++) {   // 다음 도시 v (미방문)
        if ((mask >> v) & 1) continue;
        const next = mask | (1 << v);
        const cost = dp[mask][u] + dist[u][v];
        if (cost < dp[next][v]) dp[next][v] = cost;
      }
    }
  }
  // 모든 도시 방문 후 0으로 복귀하는 최소
  let ans = Infinity;
  for (let u = 0; u < n; u++) ans = Math.min(ans, dp[FULL][u] + dist[u][0]);
  return ans;
}
```

> 상태 수 `2^N × N`, 전이 `N` → O(2^N · N²). 완전 탐색 O(N!)을 지수로 줄인 고전. N ≤ 약 18까지 가능.

## 5. JS에서의 주의점 (32비트 한계)

JS 비트 연산은 피연산자를 **32비트 정수**로 변환한다. `1 << 31`은 음수가 되고, 32비트를 넘는 비트는 잘린다.

```javascript
1 << 31;          // -2147483648 (부호 비트)
1 << 32;          // 1 (32로 나눈 나머지 → wrap)
(1 << 31) >>> 0;  // 2147483648 (부호 없는 해석)
```

- N ≤ 30 정도면 안전. 그 이상의 비트 집합은 `BigInt`(`1n << 40n`)나 배열로 나눠 표현해야 한다.
- 부호 없는 시프트는 `>>> 0`로 보정.

---

## 6. 시간복잡도

| 작업 | 복잡도 |
|------|--------|
| 모든 부분집합 순회 | O(2^N) |
| 각 마스크의 부분집합까지 순회 | O(3^N) |
| 비트마스크 DP (TSP류) | O(2^N · N²) |
| 단일 비트 연산 | O(1) |

## 7. 면접 포인트

**Q. 비트마스크는 언제 쓰나요?**
> 원소 수가 작을 때(대략 N ≤ 20) 부분집합/방문상태를 정수 하나로 압축해 집합 연산을 O(1) 비트 연산으로 처리하거나 DP 상태로 삼을 때. 집합 합·교·차가 `|`, `&`, `& ~`로 끝난다.

**Q. `mask & (mask - 1)`과 `mask & (-mask)`의 의미는?**
> 전자는 최하위 1비트를 끄고(가장 오른쪽 원소 제거), 후자는 최하위 1비트만 남긴다(LSB 추출). popcount나 부분집합 순회에 쓰인다.

**Q. 비트마스크 DP로 TSP를 어떻게 푸나요?**
> 상태를 (방문한 도시 집합 mask, 현재 도시)로 정의해 `dp[mask][u]`를 채운다. 상태 2^N·N, 전이 N으로 O(2^N·N²)이며, 완전탐색 O(N!)을 지수로 줄인다. N이 약 18 이하일 때 적용한다.

**Q. JS에서 비트마스크의 한계는?**
> 비트 연산이 32비트 정수로 동작해 `1 << 31`은 음수, `1 << 32`부터는 wrap된다. N이 30을 넘으면 BigInt나 배열 분할이 필요하고, 부호 없는 값은 `>>> 0`로 보정한다.

**Q. 한 마스크의 모든 부분집합을 어떻게 순회하나요?**
> `for (let sub = mask; ; sub = (sub-1) & mask)`로 mask에 포함된 비트만 유지하며 내려간다. 모든 마스크에 대해 부분집합까지 도는 총비용은 O(3^N)이다.
