Two Pointers Pattern

Two Sum II 시각화

정렬된 배열에서 두 수의 합이 목표값이 되는 인덱스를 찾습니다.
왼쪽 포인터(파랑)와 오른쪽 포인터(빨강)를 양 끝에서 시작해 좁혀갑니다.

설정
배열 시각화
arr[L]–
+
arr[R]–
=
합–
vs
target–
✅ 정답을 찾았습니다!
❌ 해당 target을 만드는 쌍이 없습니다.
스텝 설명
"다음 스텝" 버튼을 눌러 알고리즘을 시작하세요.
스텝 수 0
비교 횟수 0
상태 대기
알고리즘 코드 (JavaScript)
복잡도 분석
시간 복잡도O(n)
공간 복잡도O(1)
전제 조건배열이 오름차순 정렬되어 있어야 함
포인터 이동 규칙합 > target → R 왼쪽으로
합 < target → L 오른쪽으로
합 = target → 정답!
최악의 경우두 포인터가 서로 만날 때까지 n번 이동
vs. 브루트 포스O(n²) → O(n)
