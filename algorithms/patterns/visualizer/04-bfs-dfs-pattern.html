BFS vs DFS 비교

BFS — 너비 우선 탐색

  • 시간 복잡도 O(V + E)
  • 공간 복잡도 O(V)
  • 자료 구조: 큐 (Queue)
  • 가중치 없는 그래프의 최단 경로 탐색
  • 시작 노드에서 가까운 노드부터 탐색
  • 레벨 순서(Level-order) 탐색
  • 소셜 네트워크 친구 추천 (N촌 이내)
  • 웹 크롤러 — 링크 레벨 탐색
  • 지도 최단 거리 계산 (미로, 격자)

DFS — 깊이 우선 탐색

  • 시간 복잡도 O(V + E)
  • 공간 복잡도 O(V)
  • 자료 구조: 스택 (Stack) / 재귀
  • 한 경로를 끝까지 탐색 후 백트래킹
  • 깊은 솔루션을 찾을 때 BFS보다 메모리 효율
  • 위상 정렬 (Topological Sort)
  • 사이클 감지 (Cycle Detection)
  • 연결 요소(Connected Components) 파악
  • 미로 생성 알고리즘

상세 비교표

항목 BFS DFS
탐색 방식 너비 우선 (계층별) 깊이 우선 (경로별)
사용 자료구조 큐 (FIFO) 스택 (LIFO) / 재귀
최단 경로 보장 ✓ 가중치 없는 그래프 ✗ 보장 안 됨
메모리 사용 상대적으로 많음 상대적으로 적음
완전성(Completeness) ✓ 유한 그래프에서 보장 ✓ (무한 그래프 제외)
주요 활용 최단 거리, 레벨 탐색 백트래킹, 위상정렬, 연결성
