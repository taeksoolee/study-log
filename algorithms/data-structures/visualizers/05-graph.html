BFS 너비 우선 탐색

시작 노드에서 가까운 노드부터 순서대로 방문합니다. 큐(Queue)를 사용하며 최단 경로 탐색에 유용합니다.

  • FIFO 큐 사용
  • 최단 경로 보장
  • 넓게 퍼지며 탐색
시간 O(V+E)
공간 O(V)

DFS 깊이 우선 탐색

한 방향으로 최대한 깊이 탐색한 후 되돌아옵니다. 스택(Stack)을 사용하며 경로 찾기, 사이클 감지에 활용됩니다.

  • LIFO 스택 사용
  • 메모리 효율적
  • 깊게 파고드는 탐색
시간 O(V+E)
공간 O(V)

사용 방법

  • 노드를 드래그해서 이동
  • 노드 추가 후 엣지 연결
  • 시작 노드 입력 후 탐색 실행
  • 탐색 중 중단 불가
