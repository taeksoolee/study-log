해시 테이블

해시 함수로 키를 버킷 인덱스로 변환해 저장하는 자료구조입니다. 충돌 해결은 체이닝(Separate Chaining) 방식을 사용합니다.

해시 테이블 (크기: 8)
해시 계산 과정
키를 입력하고 연산을 실행하면 해시 계산 과정이 여기에 표시됩니다.
해시 함수 설명
🔑 해시 함수란?
임의 크기의 데이터를 고정된 크기의 값(해시값)으로 변환하는 함수입니다. 같은 입력에는 항상 같은 출력이 나오며(결정론적), 키를 배열의 인덱스로 빠르게 매핑해 O(1) 평균 접근을 가능하게 합니다.
hash(key) = (각 문자 코드의 합) % 테이블 크기
➗ 왜 나머지(%)를 쓰나요?
나머지 연산(모듈로)은 어떤 큰 숫자도 0 ~ (크기-1) 범위의 인덱스로 변환합니다. 예: 530 % 8 = 2 → 버킷 2에 저장. 이렇게 배열 범위를 벗어나지 않도록 보장합니다.
⚡ 좋은 해시 함수의 조건
  • 균등 분포 — 버킷에 고르게 분산
  • 결정론적 — 같은 키 → 같은 버킷
  • 빠른 계산 — O(키 길이)여야 함
  • 낮은 충돌률 — 다른 키가 같은 버킷이 되는 경우 최소화
🔗 충돌 해결 — 체이닝
같은 버킷에 여러 키가 할당되면 연결 리스트로 이어 저장합니다. 로드 팩터(항목 수 / 테이블 크기)가 0.75를 초과하면 리해싱(rehashing)을 권장합니다. 이 시각화에서는 테이블 크기 8을 사용합니다.
